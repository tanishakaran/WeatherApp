# 🌤️ Let's Know Weather
A stylish and feature-rich **Weather Web App** that gives you current weather updates, voice search, theme toggle, 5-day forecast charts, 
— all beautifully wrapped in animated UI effects like particles and waves.

> ⚡ Made with ❤️ by **Tanisha Karan**
---
## 🔍 Features
- 🔎 Search weather by **city name**
- 📍 Get weather using **your current location**
- 🎙️ **Voice search** using microphone
- 🌙 Switch between **light & dark themes**
- 📈 **5-Day forecast chart** using Chart.js
- 🌊 Animated **wave footer**
- ☁️ **Particle cloud animation** in background
- 💬 Motivational **weather-based quotes**
- 🕓 View recent city searches (**local storage**)

## 🛠️ How to Use Locally

1. **Clone this repository**
   ```bash
   git clone https://github.com/your-username/weather-app.git
   cd weather-app
   ```

2. **Replace your OpenWeatherMap API key**  
   Open `script.js` and replace:
   ```js
   const apiKey = "your_api_key_here";
   ```

3. **Open the app**
   Just open `index.html` in your browser.
